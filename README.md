🏡 Global Airbnb Performance Dashboard (Power BI)

📌 Overview
Interactive Power BI dashboard analyzing global Airbnb data to track listings growth, pricing, reviews, ratings, and city-wise performance.

🎯 Key Insights
Total Listings: 279K+ across 10 cities
Paris, NYC & Sydney contribute ~50% of listings
Entire homes generate highest revenue
98.8% users leave ≤3 reviews
66.9% users have verified identity
📊 Features
📈 Listings growth lifecycle (2008–2021)
🌍 Market share by city
💰 Price comparison by room type
⭐ Ratings analysis (cleanliness, location, value)
📅 Seasonality trends
🔍 Review frequency insights

🚀 How to Use
Open .pbix in Power BI Desktop
Use filters to explore insights
